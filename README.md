# TrailBuddy

TrailBuddy turns a little free time into a reason to step outside. Share a
neighborhood, your mood, and how long you have; it suggests three low-fuss
activities and what to bring. Pick one, put the phone away, and go.

## Why open AI?

TrailBuddy uses [Qwen 2.5 3B](https://ollama.com/library/qwen2.5) through
[Ollama](https://ollama.com/), so suggestions are generated on your own device
instead of being sent to a hosted AI service. The model can be swapped with the
`TRAILBUDDY_MODEL` setting, and its prompt is part of the source code. That
keeps the experience inspectable and adaptable, with no API key or per-request
AI bill.

After Python packages and the model have been downloaded, the app and model can
run without an internet connection. If Ollama is not installed or running,
TrailBuddy clearly switches to a small set of built-in suggestions; this
fallback needs no network or model, but is not generated by AI. Location and
interest details stay on the device when using the default local Ollama
endpoint. If you configure a remote Ollama URL, requests will go to that
endpoint instead.

TrailBuddy does not query maps, weather, trail databases, or opening hours.
Its suggestions are general ideas, not verified local recommendations. Check
conditions and accessibility before heading out.

## Run it locally

You need Python 3.10 or newer. To use local AI, install
[Ollama](https://ollama.com/download), then download the model once:

```bash
ollama pull qwen2.5:3b
```

Create an environment and install the app:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows PowerShell, activate the environment with
`.venv\Scripts\Activate.ps1`.

Start Ollama if it is not already running, then start TrailBuddy from the
project root:

```bash
ollama serve
uvicorn app.main:app --reload
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). The built-in offline
suggestions also work if you skip installing or starting Ollama.

## Configure

| Environment variable | Default | Purpose |
| --- | --- | --- |
| `TRAILBUDDY_MODEL` | `qwen2.5:3b` | Ollama model tag; use another compatible local model if you prefer. |
| `TRAILBUDDY_OLLAMA_URL` | `http://127.0.0.1:11434/api/generate` | Ollama generate endpoint. |

## Run the tests

```bash
python -m unittest discover -s tests
```

## Stack

- [Qwen 2.5](https://github.com/QwenLM/Qwen2.5) (Apache-2.0 model weights),
  served locally by Ollama
- FastAPI and Python
- Plain HTML, CSS, and JavaScript; no frontend build step
